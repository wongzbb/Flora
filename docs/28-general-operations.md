# 通用 Agent 运维与恢复

## 会话目录

每个会话由一个进程独占。两个 CLI 或 Python 进程不能同时打开同一会话执行任务。状态读取命令是例外，它只读取已持久化快照。

| 内容 | 用途 |
| --- | --- |
| `terminal.json` | 自动会话 ID、目录归属、标题和时间 |
| `subagents/` | 子任务登记表、独立内核日志和结果 |
| `general.json` | 工作目录、非敏感配置、skill 内容指纹 |
| `task.json` | 当前应用任务标识与原始任务文本 |
| `result.json` | 最近一次运行结果与成果记录 |
| `observations.sqlite3` | 来源、原始内容、成果索引、界面事件与独立的后台交互日志 |
| `kernel/session.json` | 内核会话、历史、累计预算与配置指纹 |
| `kernel/turn-*.sqlite` | 每一轮的效果日志和检查点 |

不要把会话目录提交到源码仓库。来源与任务记录可能包含业务文档内容，即使配置没有密钥也不代表整个会话不敏感。示例建议把 `workspace` 与 `sessions` 分开。

应用事件最多保留最近 2000 条；后台交互日志另有 8 MiB 滚动上限，可用 `/log` 分页查看。终端展示实际模型输出、工具参数／结果和独立子 agent 状态。裁减会明确提示。显示日志不替代内核效果日志，也不会自动加入模型上下文。跨轮对话使用内核的有界精确历史，默认最多 32 轮、64 KiB，并明确记录省略数量，不把丢弃内容伪装成“长期完整记忆”。

备份时停止当前进程，再复制会话目录和工作目录。不要只复制单个 SQLite 主文件而遗漏仍存在的 WAL；不要在模型执行期间把不一致的文件快照当成可靠备份。

## 状态解释

| 状态 | 含义与处理 |
| --- | --- |
| `completed` | 程序完成；启用交付门槛时文件检查也已通过 |
| `paused` | 在下一次外部动作派发前暂停；使用 resume |
| `needs_program` | 模型未产生可接受的完整程序；查看原因，预算允许时可显式 resume |
| `budget_exhausted` | 额度不足；resume 不会重置额度 |
| `interrupted_unknown` | 已派发操作的最终结果不能确定；先核对真实外部状态 |
| `incomplete` | 运行步骤等边界使任务尚未完成；查看 reason 和轨迹 |

CLI 单次任务完成返回 0，未完成返回 2；配置/输入错误沿用顶层 CLI 的错误码。交互终端显示实际任务状态和错误提示，不把工具已派发当作任务已完成。

## 未知结果不能当作失败重试

例如，服务器已经创建订单，但返回连接中断。此时“没有收到结果”不等于“没有创建”。Flora 会把这种动作记为未知并阻止后续效果，不自动再创建一次。

处理流程：

1. 查看 `flora agent --session ... --status` 中的 trace_path。
2. 通过服务后台、订单列表或其它可信渠道，确定那个动作的真实结果。
3. 使用内核 `flora resolve TRACE EVENT_ID --outcome outcome.json --reason "实际核对依据"` 登记已确定的结果。
4. 使用 `flora agent --session ... --resume` 继续。

`outcome.json` 必须符合对应工具的实际结果 envelope，完整格式见「事件存储、恢复与重放」与 CLI `resolve --help`。不要根据猜测生成成功结果，不要编辑数据库来删掉待定事件。一般模型网络错误属于编译失败和计费不确定，不会凭空制造一个成功工具回执。

## 暂停、退出与进程异常

运行时按 Ctrl+C，在下一次 `action_selected` 或 `model_call_started` 边界处生效，在下一工具或模型请求派发前暂停。它不会强杀正在进行的支付、写入或浏览器点击，也不会把客户端中断当作取消了服务器操作。若程序先完成，任务可能直接完成而不是暂停。

退出交互终端时会请求暂停独立子 agent，并等待已开始的调用返回。模型和网络适配器有自己的超时；极端情况下，应通过宿主进程管理器处理进程并在重开后检查日志。强制结束进程可能留下未知结果，必须按上述流程恢复。

恢复保留真实效果和累计预算；相同的已结算效果由检查点消费，不重新执行。MCP 与浏览器等外部状态不在本地检查点中，重新打开客户端不会恢复旧世界。

## 终端与工作环境

Flora 是本地单用户终端应用，不提供托管登录或多租户隔离。任务输入、工具输出与文件名在终端显示前过滤控制字符；这不等于对工具内容的事实正确性做了验证。独立子 agent 的权限、预算和恢复方式见「终端、会话与子 agent」。

工具可访问的文档、网页、MCP 返回内容都可能包含提示注入。Flora 的工作说明要求把它们视为数据，确定性的权限边界限制可调用工具与路径；这不意味着能彻底解决模型层面的提示注入。重要外部写操作应使用最小的业务权限和服务自身的幂等机制。

## 常见问题

### 缺少模型或密钥

交互入口每次输入 Base URL、API Key 和 Model；恢复时保持原地址与模型。脚本入口设置 `api_key_env` 指向的环境变量。`--status` 不需要模型或工具在线。

### 输出不是严格 JSON / 内部程序不合法

这属于模型编译阶段，不会执行那段无效程序。通用入口默认请求 JSON 对象输出，但供应商不一定保证语法或 IR 正确。编译器保留严格本地检查；一次格式修复携带错误类型、行列、错误位置附近原文，以及有界的前次响应。要求重新生成完整的当前阶段程序，而不是盲目拼接缺失括号。截断响应会要求从头生成较短程序，不把残片作为成功结果。

用 `/log` 查看 `compiler_rejected` 的具体原因及后续修复输出；`/status` 显示最近结果与累计预算。检查输出是否被截断、推理 tokens 是否占满输出上限。需要调整参数时在新会话的 profile 中设置服务支持的推理选项或输出额度。如果模型给出与真实轨迹不同的证据指纹，内核会拒绝该程序；它不会替模型改写指纹或退款。修复后仍不通过会保留 needs_program，显式 `/resume` 才按当前真实上下文再次编译。

### 模型连接失败，反复 resume 也失败

先看具体分类，不能把所有错误都当作等待不够长：

| 原因 | 自动处理与下一步 |
| --- | --- |
| timeout／connection／dns | 每次编译共享最多两次有预算的恢复；持续失败时检查网络出口、地址与服务状态 |
| HTTP 408／429／500／502／503／504 | 有限退避恢复；持续限流时等待服务恢复，不要连续消耗会话额度 |
| HTTP 401／402／403 | 不自动重试；分别检查密钥、余额、模型权限 |
| HTTP 404 | 不自动重试；检查 Base URL 是否正确、模型 ID 是否存在 |
| HTTP 400／422 | 只对明确拒绝的自动添加兼容字段进行降级；其余情况检查请求配置 |
| TLS | 不自动关闭证书校验；检查证书与网络代理 |
| stream_interrupted | 丢弃未完整结束的模型程序，再在共享恢复额度内重试；不执行残片 |

`/status` 显示读取超时、响应整体时间限制和恢复次数；`/log` 显示每次实际请求、错误与等待。SSE keep-alive 会被正常消费，整体响应时间与字节上限仍然有效。普通 JSON 响应也兼容；模型发现接口 `/models` 失败不等于 `/chat/completions` 必然不可用，可以手填模型 ID。

模型请求只生成程序，尚未执行工具，因此可单独恢复。已经执行的工具不会随模型重试而再派发。即使响应丢失也可能产生模型费用；每个请求都计入 model_calls，用量未知时按完整输出预留计费并增加 unknown_usage_calls。`/resume` 不会清空这些记录，也不能修复错误的地址、过期密钥或持续故障的服务。

### 搜索被限流或挑战

配置自己的 Brave/Tavily/SearXNG。网页工具直接连接目标 IP；要求代理的环境需先配置受控网络出口。模型 API 可达不代表所有公网域名都能由网页客户端解析。

### PDF 没有文字

检查是否是扫描件。内置解析器不做 OCR。使用经过授权的 OCR 服务或先在外部提取文字，再作为附件输入。

### 文件修改失败

确认父目录存在；新文件用独占创建，修改已有文件需要刚读到的完整 SHA-256。遇到并发修改，重新读取并决定如何合并，不能强行覆盖。

### 重开提示配置或技能变化

使用创建会话时的模型、工具目录、工作目录与技能内容；有意更换配置时建立新会话。不要直接改写指纹绕过一致性检查。

### MCP 连接失败

确认命令可执行、环境映射齐全、服务支持 stdio 或 Streamable HTTP、白名单工具真实存在。初始化失败不会降级成“连接成功但没有工具”。服务的业务错误与通信中断按不同结果处理。

### 浏览器启动失败

确认 Playwright Python 包和对应 Chromium 版本已安装、系统库齐全、宿主允许浏览器子进程运行。先在目标环境运行一个简单 Playwright 页面测试，再启动 Flora 浏览器工具。当前环境的适配器测试不能替代目标机器上的浏览器运行检查。

## 验证边界

确定性回归、协议夹具、真实模型任务和真实公网/浏览器交互是不同类别。查看 `general-agent` 分支的 `reports/TERMINAL_VALIDATION.md` 和 `reports/GENERAL_VALIDATION.md` 获取执行环境、逐类结果与未验证项。通过几项任务不等于在所有模型、所有网站上具有统一成功率，也不等于完成了生产安全审计或并发压力测试。
