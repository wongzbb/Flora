# 执行架构与能力边界

Flora 是一个独立的 Python agent 运行时。固定语言模型生成受限制的程序；运行时在内部比较候选计算，只执行一条真实的外部轨迹；消费者检查为程序修改提供局部证据。它没有借用 JAZ 的解释器，没有 `realize` 包装层，也不训练模型权重。

## 本版本交付什么

本版本包含独立 IR 与解释器、候选调度、显式工具效果、消费者合约、有限谓词规则综合、预测诊断、模型编译器、持久化事件记录、CLI、可运行离线示例和完整文档。核心运行依赖仅为 Python 标准库。模型接口使用可配置的 Chat Completions 风格 HTTP 请求；不绑定某个模型供应商。

这里的“未决”是程序状态，不是一个鼓励模型多想一会儿的提示词。几个候选能够在同一组实际输入上运行到下一次外部请求；在工具调用之前，解释器会停下来。不同候选提出相同请求时，可以共享这个真实事件；提出不同请求时，只选择一个动作，其余候选不能继续假装身处旧世界。

## 一个完整工作周期

1. 编译器读取原任务、可用工具、已发生的观察和剩余预算。
2. 编译器输出候选程序、默认候选以及可选的诊断程序。
3. 纯解释器将候选运行到工具请求、返回、具体错误或未知边界。
4. 调度器提交一个真实动作；诊断额度与普通动作共享预算。
5. 真实返回恢复匹配的续行；不同路径的续行被冻结。
6. 消费者检查记录局部兼容、失败见证和未知情况，供后续程序修订使用。

模型可以提出程序，但不能通过一句“已验证”制造合约证据。合约证据由解释器在允许的数据上运行检查产生。预测可以被真实观察反驳，但候选由于路径不同而被冻结，不能算作“预测错误”。

## 先了解四个边界

| 边界 | 可以做 | 不能据此声称 |
| --- | --- | --- |
| 纯计算边界 | 检查已知数据上的程序行为、内部错误和下一次请求 | 已经知道未调用工具的返回 |
| 真实效果边界 | 使用任务原本开放的工具执行一次动作 | 可以回滚或并行运行多个环境 |
| 合约证据边界 | 检查局部定义性、行为兼容、具体来源引用 | 已证明任意任务正确 |
| 模型边界 | 生成实现、诊断和有条件的预测 | 得到了真实世界模型或额外标签 |

## 直接使用接口与内核的关系

`Agent` 与 `invoke` 管理工具注册、模型编译、会话、预算和结果；CLI 复用同一个入口。普通用户提交自然语言任务，内部语言属于模型与运行时之间的机器接口。诊断和合约默认仍参与执行，并未因为简化入口而被移除。

实际工具结果要求新的语言理解时，程序可以通过 `replan` 请求再次编译剩余任务。状态来自已实际运行的寄存器和真实观察；这一步消耗同一预算，不产生额外世界分支。默认正常候选的 replan 才驱动实际下一步编译，假想分支不能冒充模型已经理解了未知返回。

阅读后续章节可以手工构造小型 IR 来检查具体语义，但这不是使用 Agent 的前置要求。低层 API 保留给运行时扩展、受控实验和故障诊断。

## 版本承诺

Flora 是可运行、可检查的研究工程实现。测试通过说明指定检查在交付环境下通过，不等于分布式 exactly-once、任意第三方工具安全、形式化任务正确性或生产认证。真实模型任务性能需要在指定模型、任务和预算下另行测量。
