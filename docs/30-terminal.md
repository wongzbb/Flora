# 终端、会话与子 agent

## 命令行参考

| 命令或参数 | 行为 |
| --- | --- |
| `flora` | 引导连接模型，在当前目录新建自动命名的会话 |
| `flora agent` | 同一交互入口 |
| `-C DIR` / `--workspace DIR` | 指定已存在的工作目录 |
| `--resume` | 交互选择该目录的会话 |
| `--resume ID` | 打开完整 ID 或唯一前缀所指定的会话 |
| `--config FILE` | 为新会话加载高级 JSON profile |
| `--allow-commands` | 为主 agent 授予命令执行能力 |
| `--no-subagents` | 新会话不提供委派工具 |
| `--plain` | 不使用彩色像素形象、动画和增强输入 |
| `--help` / `--version` | 查看帮助或版本，不请求凭据 |

首次连接不要求创建配置文件、命名 session 或填写工作目录。`--resume` 是会话选择操作，`/resume` 是已打开会话中未完成任务的继续操作。两者不能混为“自动重试”。

工作目录按规范化后的真实路径识别，符号链接别名映射到同一目录。不同目录的会话不会混在同一个列表里。目录移动或重命名后会被视为另一处工作环境；不要手动改写会话的配置指纹。

## 输入、模型和凭据

Base URL 与 Model 使用普通文本输入；API Key 使用隐藏输入。不要在值两端加引号。启动引导不会保存 API Key，不会导出到环境变量，也不会把它传给子进程命令。模型传输对象在内存中持有本次密钥，关闭应用时解除引用；这不是对 Python 内存进行密码学擦除的承诺。

非敏感的模型和连接设置保存在会话 profile 中。恢复时仍重新询问三个字段，并要求地址与模型匹配原会话；密钥可以轮换。工具、技能、编译器参数和累计预算保持原记录。

模型发现调用 `{base_url}/models`。收到的有效模型 ID 全部展示，不按厂商筛选或只取前几项。标准分页自动获取；遇到格式异常、网络错误、超过 4 MiB 单页上限、100 页上限或约 30 秒发现窗口，会明确提示列表可能不完整。HTTP 认证失败、没有 models 接口或空列表时仍允许手填。模型发现拒绝重定向，避免把 Authorization 转交其他地址。

普通终端推荐至少 80 列。窄屏会简化欢迎区域；`NO_COLOR` 或 `--plain` 启用简洁显示。`TERM=dumb` 不使用交互动画。程序输出与文件名中的终端控制码在显示前过滤。

## 键盘和斜杠命令

| 操作 | 行为 |
| --- | --- |
| Enter | 发送当前输入 |
| Alt+Enter | 插入换行 |
| Tab | 补全斜杠命令 |
| 上／下方向键 | 回看本次输入及该会话保留的任务文本 |
| Ctrl+C（输入时） | 清空输入，继续等待 |
| Ctrl+C（运行时） | 请求在下一执行边界暂停 |
| Ctrl+D（空输入时） | 保存退出 |

密钥提示有独立的临时输入对象，不进入任务输入历史。任务输入历史只驻留当前进程；重新启动后从保留的对话记录恢复。

| 命令 | 参数与说明 |
| --- | --- |
| `/help` | 快捷键和命令 |
| `/status` | 主任务、会话路径、主 agent 预算及子 agent 独立账本 |
| `/agents` | 子 agent 名字、ID、任务、状态 |
| `/agent ID [OFFSET]` | 子任务结果的字符窗口；默认从 0 开始，每次最多 6000 字符，按 next_offset 继续 |
| `/resume-agent ID` | 显式恢复指定子任务，完成过的子任务直接返回结果 |
| `/resume` | 继续当前主任务的检查点 |
| `/history` | 保留的已完成轮次；遗漏旧轮次的数量会提示 |
| `/sources [OFFSET]` | 来源索引分页；后续 offset 取返回记录 |
| `/artifacts` | 登记成果与当前文件哈希是否匹配 |
| `/attach PATH` | 为下一条任务附加工作目录内的常规文件路径，最多 8 MiB |
| `/new` | 创建独立会话，保留当前进程的模型连接 |
| `/exit` 或 `/quit` | 退出 |

路径可包含空格，`/attach` 后面的整段文字按路径处理。附件必须在当前工作目录内；不会将附件内容偷偷注入系统指令。读取后的内容仍按不可信任务材料处理。

## 会话位置和历史

默认存储位置为 `$XDG_STATE_HOME/flora/projects/<目录哈希>/<会话ID>`；未设置 XDG_STATE_HOME 时为 `~/.local/state/flora/projects/...`。可以用 `FLORA_STATE_HOME` 指定另一个持久目录。在 WSL 中使用的是 Linux 用户的目录。

每个会话 ID 由本地日期、时间与随机后缀生成，用户无需手动命名。第一条任务自动成为列表标题。应用会话文件与工作目录分离。标题、对话、文档原文和来源可能涉及业务数据，请按实际内容保护会话目录。

`terminal.json` 保存 ID、工作目录、时间和标题；`general.json` 保存非敏感配置；`kernel/` 保存运行状态、历史、预算和效果日志；`subagents/` 保存独立子 agent 的状态与轨迹。损坏的会话会在列表中标为 damaged，不会悄悄创建一个同名新任务。

内核对话上下文最多保留 32 轮、64 KiB 精确记录。超过限制会记录 omitted_turns，不声称模型记得全部旧内容。恢复会话不会给模型提供并不存在的历史或当前世界状态。

## 独立子 agent

主 agent 在任务适合拆分时，可以调用 `spawn_agent`。每个子 agent 有独立的模型上下文、Flora 编译器／运行时、候选程序、消费者合约、效果日志和预算。它们与同一个内核中的“候选程序”是不同概念；终端只把真实子任务显示在 Subagent 区域。

主 agent 可先发起多个子任务，再通过 `wait_agents` 获取完成状态，通过 `read_agent` 分页读取真实结果。任务描述必须携带子 agent 所需上下文；子 agent 不会自动得到主 agent 的整个对话。所有子 agent 共用经过锁保护的来源账本，因此子任务返回的 src ID 可被主 agent 读取。

默认子 agent 只读：文件列表、文本读取与搜索、文档读取、表格查询、网页获取与搜索、已保存来源读取。它们不能修改工作目录、运行命令、递归创建子 agent、执行浏览器操作或调用 MCP／HTTP 服务修改工具。主 agent 集中处理写入与交付，避免并行编辑冲突。

子 agent 的结论不是自动验证过的事实。主 agent 需要检查来源与局限；各自的源数据仍要用实际回执支撑。普通任务可以完全由主 agent 执行，界面不会为了展示多 agent 而创建空角色。

## 子 agent 配置与资源上限

```json
{
  "general": {
    "subagents": {
      "enabled": true,
      "max_parallel": 3,
      "max_children": 8
    }
  }
}
```

`flora` 交互入口默认启用。Python API 与显式 session 脚本只有配置 enabled 才启用。max_parallel 允许 1–4；max_children 允许 1–32，是整个会话累计可创建的子任务数量，已完成任务仍占名额。超过配额需复用已有 ID 或新开对话，不能通过失败重启退款。

每个子 agent 的固定预算上限为 8 次模型调用、40 次工具调用、240,000 输入 token、96,000 输出 token、600 秒墙钟预算。每次模型输出上限取父配置与 12,000 中的较小值。未知用量沿用内核的保守预留计费规则。

子任务预算与主任务分别记录，主任务 budget 数字不包含子任务消费。默认配置下子任务层最多为 8 份上述预算，外加父任务预算。输入 token 只能在服务返回计量后检查；这些限额不代表精确的货币账单硬上限。

退出会请求子 agent 在边界暂停并等待已经开始的调用返回。恢复父会话时，上次留下的 queued/running 子任务标为 interrupted，不自动发起模型请求。`/resume-agent ID` 才继续，保持原预算和日志；若内核已提交完成但状态更新前进程结束，恢复从完成记录读取结果，不重跑该任务。

## 脚本与 Python 集成

自动化脚本可使用显式 session 接口；其凭据来自配置指定的环境变量，不经过交互提示：

```bash
flora agent "读取附件并生成摘要" --workspace ./workspace --session ./sessions/task --config profile.json --json
flora agent --session ./sessions/task --status
flora agent --session ./sessions/task --resume --json
```

这种由调用者管理路径的 session 不自动出现在目录索引的 `--resume` 列表中；用原来的 `--session` 路径打开。自动索引会话的完整路径可在 `/status` 中查看，也可以使用该路径进行离线状态检查。

高级宿主可通过 `GeneralAgent(..., session_key=key)` 提供进程内凭据，或者继续使用 `api_key_env`。该参数不会写进 profile 或会话指纹。具体接口见 GeneralAgent API 章节。
