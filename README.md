# Flora 总览页

下载 `index.html` 后用浏览器打开。页面包含 Coding Agent、Core、代码、文档和实验入口；论文入口目前标记为筹备中。

- 单文件 HTML，CSS、脚本、像素角色与 Logo 均内嵌；无外部字体、图片或分析脚本。
- `flora-logo.svg` 是可单独使用的原创像素花朵 Logo，背景透明。
- 核心代码节选对应 `core` 分支，源码链接可直接查看完整实现。
- 项目入口分别连接 `coding-agent`、`core` 和 `docs`；仓库访问权限由 GitHub 控制。

本分支存放静态页面源码，不代表已经开启 GitHub Pages。页面保留窄屏布局、键盘导航、代码切换和复制功能。
