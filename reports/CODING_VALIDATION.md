## 内核与边界

本功能新增 `coding/` 应用层和 CLI 路由，复用原 `Agent`、编译器、调度器、合约、诊断、工具执行和会话恢复。没有修改双重控制或可综合合约内核，也没有新增已知正确答案、世界快照或训练需求。

该样例验证真实模型与编码流程贯通，不构成大型仓库成功率、OpenHands 对比、正式 benchmark 或双重控制增益的证据。当前是可直接运行的本地 Coding Agent；没有 Web IDE、容器调度或生产多租户服务。

worktree 不提供宿主权限隔离。测试结果仅覆盖固定命令和 Git 可见文件版本，不覆盖被忽略的文件、外部依赖与任务全部语义。支持范围和操作说明见 docs 分支的 Coding Agent 章节。
